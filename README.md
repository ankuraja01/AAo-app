<h1 align="center">AAo</h1>
<p align="center"><b>Connect. Communicate. Earn.</b></p>

AAo is a messaging app for Android and Windows with its own in-app reward points.

This repository is only for **downloading the app**. The source code is private.

## Download

Go to **[Releases](../../releases)** and download the file for your device:

| Device | File |
|---|---|
| Android | `AAo-<version>.apk` |
| Windows | `AAo-<version>-windows.zip` |

> No public release has been published yet. The first release is being prepared.

### Install on Android

1. Download the `.apk` file on your phone.
2. Open it. If Android asks, allow installing apps from this source.
3. Tap **Install**.

### Install on Windows

1. Download the `-windows.zip` file.
2. Extract it to a folder.
3. Run `xconnect.exe`. Windows SmartScreen may warn you because the app is new; choose **More info → Run anyway** only if you downloaded it from this page.

## Verify your download

Each release lists a SHA-256 checksum for every file. Only install files downloaded from this repository's Releases page.

## Good to know

- Messages are protected in transit (HTTPS/TLS). AAo does **not** offer end-to-end encryption yet.
- Reward points are in-app rewards only and have **no cash value**.

Found a problem? Open an issue in this repository with your device, app version and what happened.
